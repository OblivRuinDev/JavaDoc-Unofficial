## 分支内容与目的

-   **原始文档镜像**：本分支中的所有 HTML 文件均源自本仓库的 [`en`](https://github.com/OblivRuinDev/JavaDoc-Unofficial/tree/en) 分支，是原始英文文档的完整镜像。
-   **中文翻译**：在原始英文文档的基础上，对其中的**文本内容**（如类说明、方法描述等）进行了中文翻译。**所有原始代码示例、接口定义、以及 Oracle 的版权和商标声明均被完整保留，未经修改**。
-   **目的**：本翻译旨在帮助中文开发者更好地理解 Java SE API，仅供**个人学习、研究和参考**之用。
